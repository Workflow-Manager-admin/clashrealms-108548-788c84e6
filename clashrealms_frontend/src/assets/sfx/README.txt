Place your sound effects here:
- click.mp3: UI button clicks, navigation, menus.
- upgrade.mp3: Success, upgrade, celebration actions.

Place .mp3 (or .wav) files named exactly as above into this folder.
Example sources: https://freesound.org/ or your own assets.

You may need to add the actual sound files before running in browser; otherwise, SoundManager will not play SFX.
